DKAN is a powerful, community-driven open data platform that has been at the forefront of data accessibility and transparency for over a decade. As a Drupal module, DKAN leverages Drupal's robust features to create modern, standards-focused, and API-first open data catalogs for a variety of specific use cases. DKAN is proudly maintained by [@CivicActions](https://github.com/CivicActions/), who have been leaders in Open Source solutions for government and nonprofit organizations for 20 years.

## DKAN Projects on Drupal.org

The main project repositories have permanently moved to Drupal.org:

* **[DKAN](https://www.drupal.org/project/dkan)**: The DKAN Open Data catalog module

Additional modules are also hosted at Drupal.org that are dependencies of or extensions to DKAN core:

* **[JSON Form Widget](https://www.drupal.org/project/json_form_widget)**: Create Drupal forms from JSON Schema documents
* **[DKAN DCAT-US v3 Bridge](https://www.drupal.org/project/dkan_dcatus3_bridge)**: Make a DCAT-US 1.1-based DKAN catalog DCAT-US 3.0-compliant
* **[DKAN Dataset Archiver](https://www.drupal.org/project/dkan_dataset_archiver)**: Archive copies of DKAN dataset resource files
* **[DKAN Automated Protection](https://www.drupal.org/project/dkan_automated_protection)**: Dynamically activate DKAN's "degraded service mode"
* **[DKAN AI Query](https://www.drupal.org/project/dkan_ai_query)**: Natural-language query widget for DKAN datasets
* **[DKAN MCP Server](https://www.drupal.org/project/dkan_mcp_server)**: Model Context Protocol server for DKAN


## GitHub Repositories

These actively maintained projects support DKAN itself or DKAN-based production sites:

* **[Data Catalog App](https://github.com/getdkan/data-catalog-app)**: Generic data catalog fronted in react for DKAN
* **[RootedJsonData](https://github.com/GetDKAN/RootedJsonData)**: Access and modify JSON-based data objects while enforcing JSON Schema
* **[Procrastinator](https://github.com/GetDKAN/procrastinator)**: Library to define jobs and run them...most likely later
* **[CSV Parser](https://github.com/GetDKAN/csv-parser)**: State-machine driven CSV parser and validator
* **[Contracts](https://github.com/GetDKAN/contracts)**: A set of interfaces
* **[cmsds-open-data-components](https://github.com/GetDKAN/cmsds-open-data-components/)**: Data catalog component library for the [CMS.gov Design System](https://design.cms.gov/?theme=core)

## Security

Most of our Drupal modules are covered by the [Drupal Security Advisory Policy](https://www.drupal.org/security-advisory-policy); report security issues for these projects using Drupal's [confidential reporting process](https://www.drupal.org/docs/develop/issues/issue-procedures-and-etiquette/reporting-a-security-issue). If you have found a vulnerability in a project on GitHub or a module not covered by the advisory policy, please report this by e-mailing dkan-security@civicactions.com.
